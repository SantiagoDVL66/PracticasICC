En esta carpeta se encuentran los archivos utilizados y relacionados a la elaboración de la práctica05
En esta práctica se hace uso de la función while y de la generación aleatoia de numeros con Math.random, 
con el fin de calcular pi con el metodo de Monte Carlo. En la segunda parte se realizo un ejercicio con 
if else para generar un codigo verificador del propio codigo, que alerte al usuario si algo en el no tiene
sentido. además de usar el ciclo for para calcular el interes compuesto y una ligera aplicación de la función 
Math.pow para calcular potencias.
Este seria el resumen e introducción de la práctica05
